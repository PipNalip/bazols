# Спецификация: Base Template v0.1

## Цель

Создать независимый white-label шаблон для безопасной разработки приложений с AI-агентом в Cursor и Hermes Agent. Шаблон помогает человеку без глубокого технического опыта формулировать задачу, строить небольшими проверяемыми шагами и не публиковать секреты.

## Пользователь

Человек создаёт личный или небольшой командный проект в Cursor, Hermes Agent либо в агенте, который читает `AGENTS.md` и поддерживает формат Agent Skills.

## Что входит

- нейтральные правила безопасности, сотрудничества, простоты, разработки через тесты и проверки;
- команды checkpoint, check, explain и release;
- переиспользуемые skills для проработки идеи, ревью плана, аудита, документации, AI-безопасности и готовности к запуску;
- защита локальных секретов для Git, Cursor и Docker;
- самодостаточный валидатор без внешних зависимостей;
- общий `AGENTS.md` с правилами, которые Hermes получает при запуске, и проектные навыки в `.agents/skills/`;
- MIT-лицензия и понятная инструкция установки.

## Что не входит

- код готового приложения и выбор языка/фреймворка;
- конкретные issue trackers, внутренние платформы, частные домены или корпоративные процессы;
- готовый deployment pipeline;
- автоматическое изменение существующего проекта;
- публикация или push на GitHub.

## Сценарии

1. Пользователь копирует шаблон в новый проект, заполняет команды стека и получает предсказуемую работу агента.
2. Пользователь добавляет шаблон в существующий проект вручную, не перезаписывая существующие файлы.
3. Перед публикацией пользователь запускает `sh scripts/validate-template.sh` и получает ошибку, если отсутствует защита секретов, сломан frontmatter или остались запрещённые внутренние маркеры.
4. Пользователь запускает Hermes из корня Git-проекта, подключает навыки и использует `/check`, `/checkpoint`, `/explain` или `/release` как эквиваленты команд Cursor.

## Acceptance criteria

- AC-1: шаблон самодостаточен и не зависит от исходного или внешнего репозитория.
- AC-2: при создании локальный Git-репозиторий не содержит remote.
- AC-3: проверка структуры подтверждает наличие правил, команд, skills, `AGENTS.md`, `.gitignore`, `.cursorignore`, `.dockerignore`, permissions и MIT License.
- AC-4: Git, Cursor и Docker ignore-файлы исключают `.env`, service-account credentials, приватные ключи и registry authentication files; Docker также исключает `.git`.
- AC-5: ни один отслеживаемый текстовый файл не содержит внутренних названий платформ, доменов, проектов или исходный корпоративный Git remote.
- AC-6: deployment policy не запрещает конкретные технологии и требует сначала зафиксировать выбранный способ доставки проекта.
- AC-7: release-команда не содержит исполняемой команды публикации и требует отдельного явного подтверждения перед push.
- AC-8: `sh scripts/validate-template.sh` и `sh tests/test-template.sh` завершаются успешно.
- AC-9: README явно разделяет поддержку Cursor и других агентов и не обещает абсолютную защиту секретов.
- AC-10: `AGENTS.md` содержит общий цикл проверки и правило остановки после трёх неудачных попыток, которые иначе остаются только в Cursor rules.
- AC-11: `.agents/skills/` содержит семь процедур с тем же содержимым, что Cursor skills, и четыре эквивалента команд Cursor; frontmatter корректен и имена совпадают с папками.
- AC-12: локальный release-навык Hermes требует отдельного явного подтверждения перед push и не содержит исполняемой команды публикации.
- AC-13: README объясняет подключение проектных навыков в актуальном Hermes, обходной путь для установленной v0.18.2 и границы применимости Cursor permissions и ignore-файлов.

## Решения

- Лицензия: MIT.
- Основной продукт — инструкции для агента, а не starter application.
- Специфичные интеграции не входят в core.
- `.agents/skills/` используется как переносимый каталог навыков. Два формата frontmatter сохраняются для Cursor и Hermes; тест сравнивает тела процедур, чтобы они не расходились.
- В корне нет Dockerfile, который притворяется универсальным; поставляется только безопасный `.dockerignore` для проектов, которые позже добавят Docker.
